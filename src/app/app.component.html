Description
Angular modal component
  • - LcModal component is an Angular component for displaying custom content in modal
  • - Show any Angular component in modal
  • - Supports multiple modals and modals inside of a modals
  • - Has maximize/restore
  • - Resizable and draggable
  • - Compatible with Angular 2+ up to Angular v18.0.0
  • - Only dependency is Font Awesome
Getting Started
  • 1. Fork and clone this repo
  • 2. npm install
  • 3. Open a terminal and type "npm run start"
  • 4. Open "http://localhost:4200" in browser
Installation
To install this component to an external project, follow the procedure:

  • 1. Install lc-modal package from npm:

    npm install @libusoftcicom/lc-modal

  • 2. Make a component

    
import { BaseModalComponent } from '@libusoftcicom/lc-modal';

@Component({
   template: `
   <form (ngSubmit)="confirm(model)"></form>
      <button type="submit">Submit</button>
   </form>
   `
})
export class ModalComponentExample extends BaseModalComponent {
   @Import()
   public data; // bind data from `params()` method
}

  • 3. Register ModalModule in NgModule with components that are opened in modal:

    
   import { ModalModule } from '@libusoftcicom/lc-modal';
   import { ModalComponentExample } from '...'; // component used in modal

    @NgModule(
      {
        declarations: [..., ModalComponentExample],
        imports: [
          ModalModule,
          ...
        ],
        providers: [...],
        bootstrap: [...]
        })
    export class AppModule {}

  • 4. Add modal anchor component

    <dialog-anchor></dialog-anchor>

  • 5. Open modal

    
    let modalResult = await this.modal
      .title('Example modal')
      .component(ModalComponentExample)
      .setHeight(370)
      .setWidth(700)
      .draggable(true)
      .showMaximize(true)
      .params({
        data: { foo: 1, bar: 2 }
      })
      .open();
Custom modal styles

Define the CSS custom properties for that modal:

Available variables:

  • --lc-modal-background - modal background
  • --lc-modal-content-background - content background
  • --lc-modal-content-padding - content padding
  • --lc-modal-width, --lc-modal-min-width, --lc-modal-min-height - modal dimensions
  • --lc-modal-top - default modal top position
  • --lc-modal-overlay-background - overlay color
  • --lc-modal-shadow - modal shadow
  • --lc-modal-border - modal border
  • --lc-modal-pseudo-background, --lc-modal-pseudo-border - resize preview styles
  • --lc-modal-header-background, --lc-modal-header-color - header colors
  • --lc-modal-header-text-color - default header text color
  • --lc-modal-header-font-size, --lc-modal-header-font-weight - header typography
  • --lc-modal-header-padding, --lc-modal-header-button-size - header spacing and button size
  • --lc-modal-header-button-color, --lc-modal-header-button-opacity, --lc-modal-header-button-hover-opacity - button appearance
  • --lc-modal-header-button-font-size, --lc-modal-header-button-font-weight, --lc-modal-header-maximize-button-font-size - button typography
  • --lc-modal-resize-color, --lc-modal-resize-inner-color - resize handle colors

The same principle can be used to define your own custom CSS class, e.g. colored-modal:

this.modal
  .component(ModalComponentExample)
  .addClass('colored-modal')
  .open();
modal-component.colored-modal {
  --lc-modal-header-background: #be185d;
  --lc-modal-header-color: #fff;
  --lc-modal-overlay-background: rgba(190, 24, 93, .35);
}

To change the look of every modal at once (a global change), override the CSS custom properties on the base modal-component selector instead of a modal-specific class, e.g. by toggling a class on <body>:

modal-component {
  --lc-modal-header-background: #11111b;
  --lc-modal-header-color: #cdd6f4;
  --lc-modal-background: #1e1e2e;
}
Custom header component

The default modal header can be replaced with your own component, implementing IModalHeaderComponent:

@Component({
  selector: 'custom-modal-header',
  standalone: true,
  template: `
    <div class="custom-modal-header">
      <span>{​{ title() }​}</span>
      <button (click)="close()">&times;</button>
    </div>
  `
})
export class CustomHeaderComponent implements IModalHeaderComponent {
  title = input.required<string | null>();
  configuration = input.required<ModalConfiguration>();

  private closeFn: () => void = () => {};

  setCloseFn(fn: () => void): void {
    this.closeFn = fn;
  }
}

1. Use it for a single modal by calling .header() on the modal instance:

this.modal
  .title('Custom header modal')
  .component(ModalComponentExample)
  .header(CustomHeaderComponent)
  .open();

2. Or replace the default header for every modal in the app by providing it through the MODAL_HEADER token, e.g. via ModalModule.forRoot() in AppModule:

ModalModule.forRoot({
  header: GlobalModalHeaderComponent
})

which is equivalent to providing it directly:

providers: [
  withModalHeader(GlobalModalHeaderComponent)
]

3. In a standalone app (no AppModule), ModalModule still needs to be imported once for its own providers (Modal, ModalHelper, ModalConfig), but withModalHeader() is a plain Provider and can be added on its own, next to it, in bootstrapApplication():

bootstrapApplication(AppComponent, {
  providers: [
    withModalHeader(GlobalModalHeaderComponent)
  ]
});
Config options 

this.modal
  .title('Example modal')
  .setHeight(370)
  .setMinHeight(300)
  .setMaxHeight(500)
  .setWidth(700)
  .setMinWidth(400)
  .setMaxWidth(700)
  .params({ })
  .draggable(false)
  .resizable(true)
  .closeOnClick()
  .offsetLeft( 200 )
  .offsetTop( 200 )
  .closeOnError()
  .preClose(() => Promise.resolve() )
  .showClose( true/false )
  .confirm( { data } )
  .cancel()
  .setClass('test-class')
  .removeClass('test-class')
  .component(ModalComponentExample)
  .loadCompone(async () => import('./modal-example2/modal-example.component').then((m) => m.ModalComponentExample2))
  .draggable(true)
  .showMaximize(true)
  .onlyLastModalActive(false)
  .header(CustomHeaderComponent)
  .open();
title
Set modal title.
setHeight
Set modal height.
setWidth
Set modal width.
draggable
Enable/disable changing modal position.
resizable
Enable/disable changing modal size.
closeOnClick
Enable/disable closing modal on background click.
offsetLeft
Set modal position from left side of browser window.
offsetTop
Set modal position from top of browser window.
closeOnError
Enable/disable closing modal on error.
preClose
Set function that is executed before closing modal.
showClose
Show/hide modal close button.
confirm
Close modal with confirmation.
cancel
Close modal without confirmation.
setClass
Set custom css class on modal.
removeClass
Remove custom css class on modal.
component
Set modal component.
loadComponent
Dynamic component loading.
draggable
Enable/disable modal dragging.
showMaximize
Show/hide modal maximize button.
onlyLastModalActive
Enable/disable onlyLastModalActive.
open
Open modal.
